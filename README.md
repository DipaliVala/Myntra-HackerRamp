## 📖 Overview

Myntra-HackerRamp is a full-stack developer platform that integrates interactive shopping, multimedia messaging, and real-time video communication to create engaging retail experiences. Built with modern technologies, it supports scalable, responsive applications tailored for innovative fashion and social platforms.

### Why Myntra-HackerRamp?

This project empowers developers to build dynamic, real-time web applications with seamless data flow and user engagement. The core features include:

- 🧩 **Modular Architecture**: Supports scalable development with a clean separation of frontend, backend, and real-time communication layers.
- 💻💬 **Real-Time Messaging**: Enables live chat, multimedia sharing, and user presence updates for interactive user experiences.
- 🎥🌐 **Video Streaming**: Integrates virtual meeting capabilities using Zego SDK for seamless video communication.
- 🚀⚙️ **Responsive UI**: Built with React and Tailwind CSS for a scalable, maintainable, and visually appealing frontend.
- 🔍🔐 **User Management**: Facilitates authentication, profile editing, and user search for personalized interactions.

## 🛠️ Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language**: JavaScript  
- **Package Manager**: Npm

---

### 📦 Installation

Build Myntra-HackerRamp from the source and install dependencies:

1. **Clone the repository:**
```bash
git clone https://github.com/DipaliVala/Myntra-HackerRamp
```
2. **Navigate to the project directory:**
```bash
cd Myntra-HackerRamp 
```
3. **Install the dependencies:**
```bash
npm install
```
### ▶️ Usage
Run the project with:
```bash
npm start
```
### 🧪 Testing

Myntra-HackerRamp uses the Jest test framework. Run the test suite with:
```bash
npm test
```
